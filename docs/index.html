რა არის სკაუტინგი
სკაუტინგი იყენებს არაფორმალური განათლების პროგრამას, რომელიც ორიენტირებულია პრაქტიკულ გარე აქტივობებზე, როგორიცაა: კემპინგი, აკვატიკა, ლაშქრობა და სპორტი. სკაუტური მოძრაობის საყოველთაოდ აღიარებული მახასიათებელია სკაუტური ყელსაბამით და უნიფორმა.
სკაუტინგი ქქსმო-ში
KKOSM- ქვემო ქართლის ოფიციალური სკაუტური მოძრაობა ატარებს სკაუტინგის კურსებს ქალაქ რუსთავში ყოველ სეზონზე.KKOSM- ქვემო ქართლის ოფიციალური სკაუტური მოძრაობა ატარებს სკაუტინგის კურსებს ქალაქ რუსთავში ყოველ სეზონზე.KKOSM- ქვემო ქართლის ოფიციალური სკაუტური მოძრაობა ატარებს სკაუტინგის კურსებს ქალაქ რუსთავში ყოველ სეზონზე.
