რა არის სააგენტო

სააგენტო უზრუნველყოფს კვალიფიციური საგანმანათლებლო მომსახურების მიწოდებას ახალგაზრდებისთვის, რომელიც ხელს უწყობს მათ განვითარებას და დამოუკიდებელი, აქტიური მოქალაქეების ჩამოყალიბებას.

ჩვენი მიზანია შევქმნათ ისეთი გარემო, სადაც ახალგაზრდები შეძლებენ საკუთარი პოტენციალის სრულად გამოვლენას და რეალიზებას.

საზაფხულო ქემფში-ში

KKOSM - აქვს უნიკალური საზაფხულო ბანაკები, რომლებიც მდებარეობს ბუნების წიაღში, საქართველოს სხვადასხვა რეგიონში. KKOSM-ის საზაფხულო ბანაკები წარმოადგენს არაფორმალური განათლების საუკეთესო მაგალითს, სადაც ახალგაზრდები სწავლობენ თამაშით, სხვადასხვა აქტივობებით და ვორქშოფებით.

ჩვენი პროგრამები

სააგენტო უზრუნველყოფს კვალიფიციური საგანმანათლებლო მომსახურების მიწოდებას ახალგაზრდებისთვის, რომელიც ხელს უწყობს მათ განვითარებას. ბანაკებში სხვადასხვა საგანმანათლებლო და გასართობი აქტივობები ტარდება, რომელიც ხელს უწყობს მონაწილეთა უნარების განვითარებას.
